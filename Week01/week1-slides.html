The one idea to remember

Robot code runs on a loop

Initruns ONCE

Runs the instant a mode starts. Put one-time setup and messages here.

Periodic~50× / second

Runs every ~20 ms while in that mode. This loop is the robot’s heartbeat.

teleopInit() once · teleopPeriodic() fifty times a second.

The teachable twist

Move it into Periodic…

public void teleopPeriodic() {
  System.out.println("Hello, Robot!");   // prints 50×/sec!
}

…and it floods the console — because Periodic runs 50 times a second. That’s the loop. Put one-time messages in Init instead.
