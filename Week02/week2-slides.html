Your deliverable

A helper class RobotMath you wrote, a passing test that proves it, and it running on a live joystick in the simulator.

Idea 1 — values

Robot values are doubles

double stickY = -0.42;   // joystick: -1.0 .. 1.0
double distance = 1.37;   // meters

Whole numbers (int) are rare on a robot — almost everything is a decimal.

Idea 2 — a method

A method is a machine

inputs ──►  [ deadband(value, band) ]  ──► output

Give it inputs, it returns one value. RobotMath.deadband(0.55, 0.1) returns 0.5.

Idea 3 — classes & objects

A class groups methods

Objectmade with new

An instance built from a class — has its own data.

Utility classall static — no new

RobotMath is just a bag of methods. Call them on the name: RobotMath.clamp(...).

Idea 4 — why we test

A test proves it once, forever

@Test void deadbandRescalesPositive() {
  assertEquals(0.5, RobotMath.deadband(0.55, 0.1), 1e-9);
}

On a robot you can't println your way through everything. Run tests with ./gradlew test.
